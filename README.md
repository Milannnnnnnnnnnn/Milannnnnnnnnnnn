## 📌 About Me

* ## ✦ About Me
* Hey! I'm **Milan**, a developer who enjoys turning ideas into real, working projects.
* My main focus is **Web Development**, where I enjoy building modern, responsive, and interactive websites and applications. I'm interested in both the creative and technical sides of development—from designing interfaces and creating smooth user experiences to building the logic and systems that make applications actually work.
* Beyond web development, I'm also interested in **software, hardware, electronics, and embedded systems**. I enjoy experimenting with things like **Arduino, microcontrollers, sensors, motors, servos, and DIY projects**, especially when software and hardware can be combined into something useful.
* I like learning by building. Instead of only reading about a technology, I prefer to experiment with it, create something, break things, figure out why they broke, and improve it. Every project is an opportunity to learn something new.
* I'm constantly exploring new technologies, improving my programming skills, experimenting with different ideas, and working on projects that challenge me to think differently.
* For me, programming isn't only about writing code. It's about **solving problems, creating things, experimenting, and turning an idea in my head into something that actually exists.**
